# ESB Boba Fett — DIY Soft Parts Patterns

DIY sewing patterns for *The Empire Strikes Back* Boba Fett costume.

## Available Patterns

- **Flak Vest** - in progress
- **Flight Suit** - in progress
- **Pouches** - planned
- **Gloves** - v0.3 (v0.4 in progress)
- **Leather Belt** - planned
- **Boots** - research in progress

PDF formats: **A4, A3, US Letter, US Tabloid**.

Patterns will be updated as they are tested and improved. Check each folder for the latest version and notes.

## Sizing & Printing

Patterns are based on my own measurements and may require adjustments to fit.

Print PDFs at **100% / Actual Size**. Disable “Fit to Page” or similar scaling options.
